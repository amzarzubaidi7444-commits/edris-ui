EDRIS DIALYSIS SCREEN — INSTALL

Copy these 3 files into your current edris-ui repository:

dialysis.html
assets/css/dialysis.css
assets/js/dialysis.js

Your project should become:

edris-ui/
├── index.html
├── monitor.html
├── dialysis.html
└── assets/
    ├── css/
    │   ├── styles.css
    │   ├── monitor.css
    │   └── dialysis.css
    └── js/
        ├── app.js
        ├── monitor.js
        └── dialysis.js


OPTIONAL: CONNECT YOUR EXISTING BUTTONS

HOME
In index.html find your "View →" button inside the Next Dialysis card.
Change it to:

<button class="hero-pill tap" onclick="location.href='dialysis.html'">View →</button>


MONITOR
In monitor.html find the small "Next Dialysis" card arrow.
Change it to:

<button class="mini-arrow tap" onclick="location.href='dialysis.html'" aria-label="Open dialysis details">→</button>


UPLOAD / GIT

If using PowerShell:

git status
git add dialysis.html assets/css/dialysis.css assets/js/dialysis.js
git commit -m "Add dialysis session screen"
git push origin main
