EDRIS MODERN LEARNING UI v1.3
================================

WHAT CHANGED
------------
This update redesigns the old lesson section that displayed a large clock / old-school layout.

New design:
- Real topic image thumbnail on every lesson card
- Small 3–4 min reading-time chip instead of a huge clock graphic
- Full lesson title — never intentionally truncated
- Clear lesson number (01, 02, 03...)
- Topic label + lesson status
- Working Save button on each lesson card
- Working Open Lesson action
- Modern topic hero with image + EDRIS blue/navy overlay
- Circular learning-progress indicator
- Functional Continue Learning card
- Responsive mobile, tablet and desktop layouts
- Dark-mode styling retained
- Existing Language / Text Size / Reset / Saved settings retained
